# 🌟 Student Practice Scientific Calculator

A simple and colorful **Scientific Calculator Website** made for students practice.

✅ Live Site:  
https://zainebkhalid8.github.io/ZainebKhalid8-scientific-calculator/

## 👩‍💻 Developer

## 📌 Features

- Scientific calculator (sin, cos, tan, log, ln, √, factorial, powers)
- Simple student-friendly layout
- Yellow + Blue color theme
- Left sidebar navigation:
  - Calculator
  - About
  - Resources
  - Ask Helper
- Welcome prompt for user name
- Keyboard shortcuts support

---

## ⌨️ Keyboard Shortcuts

- **Enter** → Calculate result
- **Backspace** → Delete last input
- **Esc** → Clear all
